Agro Forte, Futuro Sustentável

O Programa Agrinho é a maior iniciativa de responsabilidade social do Sistema FAEP/SENAR-PR. Há décadas, ele conecta educação e campo para formar cidadãos conscientes.

Em 2026, o tema foca no Equilíbrio. Não basta produzir; é preciso garantir que os recursos naturais (água, solo e biodiversidade) estejam disponíveis para as próximas gerações. Este site foi criado para demonstrar que a tecnologia e o manejo biológico são os maiores aliados do produtor moderno.
